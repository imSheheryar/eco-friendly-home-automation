# Eco-Friendly Home Automation Prototype

## Project Info

**Author:** Sheheryar

This is a prototype for an eco-friendly home automation system, designed to monitor and optimize energy consumption using modern web technologies.

## Tech Stack
- React
- TypeScript
- Tailwind CSS
- shadcn-ui
- Vite
- Python (for backend or data processing modules)

## Getting Started

### Prerequisites
- Node.js & npm
- (Optional) Python 3.x if using backend/data scripts

### Installation & Running Locally

```sh
# Clone the repository
git clone https://github.com/imSheheryar/eco-friendly-home-automation.git
cd eco-friendly-home-automation/prototype

# Install dependencies
npm install

# Start the development server
npm run dev
```

The app will be available at `http://localhost:5173` by default.

### Python Usage (if applicable)
If your project includes Python scripts for backend or data processing, navigate to the relevant directory and run:
```sh
python your_script.py
```
